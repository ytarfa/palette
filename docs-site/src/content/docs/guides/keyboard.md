title: Keyboard
description: Palette's shortcuts, and how to change them.
---

| Key | |
| --- | --- |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd> | Search tabs. Press P again while holding ⌘⇧ to move down the list, let go to switch |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>K</kbd> | Run a command. Press again to close |
| <kbd>></kbd> | At the start of a tab search, switches to commands |
| <kbd>⌘</kbd><kbd>⌫</kbd> | Close the highlighted tab |
| <kbd>⌘</kbd><kbd>↵</kbd> | Open a page in a new tab instead of the current one |
| <kbd>↵</kbd> | Run the item, or open its sub-list (items with a ›) |
| <kbd>⌫</kbd> | On an empty search, go back a level, or from commands back to tabs |
| <kbd>Esc</kbd> | Go back a level, or close |

On Windows and Linux, use Ctrl instead of ⌘.

## Change the shortcuts

Both shortcuts are Chrome extension shortcuts, so they work on every page and take priority over the page's own. Change them at `chrome://extensions/shortcuts`.

## Shortcuts next to commands

Commands show Chrome's own shortcut next to them when it has one, so you learn them as you go. These are only displayed: pressing them is still handled by Chrome. See [Shortcuts next to commands](../../plugins/built-in/#shortcuts-next-to-commands) for where they come from.
