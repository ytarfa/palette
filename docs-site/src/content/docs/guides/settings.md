---
title: Settings
description: Turn plugins, sites and commands on or off, and approve plugins from other extensions.
---

Open **Palette settings** from <kbd>⌘</kbd><kbd>⇧</kbd><kbd>K</kbd>, or right-click the toolbar icon and pick **Options**.

## Turn things off

Every plugin, every site and every single command has its own switch. Some, like site data, start off until you turn them on.

## Approve plugins

Plugins from other extensions wait for your approval before anything shows up. When one registers, Palette's toolbar icon shows a badge and <kbd>⌘</kbd><kbd>⇧</kbd><kbd>K</kbd> shows **1 plugin is waiting for approval**.

In settings, next to the plugin's name, description and extension ID, Palette says what the plugin will see: the current tab's site or full address, and what you type, only if it asked for them.

- **Allow** turns it on.
- **Block** turns it down.

Plugins can only be allowed from settings, never from the palette. If an approved plugin later renames itself or asks for more, it goes back to waiting. See [Plugin security](../../plugins/security/) for details.

**Manage plugins…** in <kbd>⌘</kbd><kbd>⇧</kbd><kbd>K</kbd> lists plugins so you can turn them off or remove them. Turning one back on happens in settings.
