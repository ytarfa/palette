<kbd>⌘</kbd><kbd>⇧</kbd><kbd>K</kbd> lists every command that makes sense for the current tab. Type a few letters to filter. Commands for the site you're on come first, see [Site commands](../site-commands/).

## Tabs and windows

About 30 browser commands: duplicate, pin, mute, reopen closed tab, close duplicates, move to another window, zoom and more. Chrome's own shortcuts sit next to them.

**Tab cleanup** closes every tab you haven't touched in a day, a week or a month. You see the list first, and pinned or playing tabs are never closed.

## Copy and capture

- Copy the visible area or the whole page as an image, or save it as PNG or JPG.
- Copy the URL without tracking parameters, a Markdown link, the selection as a quote, or the whole article as Markdown.

## Page tools

- Go up a level, open the page in the Wayback Machine, search the site you're on.
- Reader view, dark mode on any page, print or save as PDF.

## Open or search anything

Type a domain to open it, or any text to search with your default search engine.

## Site data

Off by default. Clear cookies and storage for the current site, or copy its cookies as a header, JSON or cookies.txt. Turn it on in [settings](../settings/).

## Plugins

Commands from [plugins in other extensions](../../plugins/external/) show up in the same list once you approve them. **Manage plugins…** lists them so you can turn them off or remove them.
