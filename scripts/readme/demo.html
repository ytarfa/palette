Getting started

Vite is a build tool that aims to provide a faster and leaner development experience for modern web projects. It has two major parts: a dev server with rich built-in features, and a build command that bundles your code for production.

To scaffold a project, run npm create vite@latest and follow the prompts. Then pick a framework and a variant, and start the dev server with npm run dev.

Vite is opinionated and comes with sensible defaults out of the box, but is also highly extensible through its plugin API and JavaScript API with full typing support.
